# 🌐 Website Biodata Diri

Website biodata diri sederhana yang dibuat menggunakan **HTML dan CSS** sebagai bagian dari pemenuhan tugas praktikum mata kuliah **Workshop Web Desain**.

## 📌 Deskripsi

Website ini berisi informasi singkat mengenai diri pembuat, meliputi biodata, deskripsi diri, hobi, keahlian, serta tautan media sosial.

Website ini juga dibuat sebagai penerapan dasar-dasar **HTML dan CSS**, khususnya dalam penggunaan struktur HTML, heading, paragraf, format teks, gambar, list, hyperlink, serta styling halaman menggunakan CSS.

## 🎯 Tujuan

Project ini dibuat untuk memenuhi tugas praktikum mata kuliah **Workshop Web Desain** serta menerapkan konsep dasar pembuatan halaman web menggunakan HTML dan CSS.

## 🛠️ Teknologi yang Digunakan

* **HTML5** — digunakan untuk membangun struktur dan konten halaman.
* **CSS3** — digunakan untuk mengatur tampilan, layout, warna, tipografi, dan responsivitas halaman.

## 📂 Struktur Project

```text
biodata-diri/
├── README.md
├── index.html
├── style-bio.css
├── .gitignore
└── assets/
    ├── my-photo.jpg
    └── favicon.png
```

## ✨ Fitur

* Informasi biodata diri
* Deskripsi singkat mengenai diri
* Daftar hobi dan keahlian
* Foto/avatar profil
* Tautan media sosial
* Tampilan responsif pada berbagai ukuran layar
* Styling menggunakan CSS

## 🖥️ Cara Menjalankan

1. Clone repository ini ke komputer.
2. Buka folder project.
3. Buka file `index.html` menggunakan browser.
4. Website biodata akan ditampilkan pada browser.
